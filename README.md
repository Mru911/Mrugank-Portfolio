# Mrugank Deshpande — Portfolio

Next.js 14 | React Three Fiber | Framer Motion | Tailwind CSS | TypeScript

## Quick start

```bash
npm install
npm run dev
# open http://localhost:3000
```

## Deploy

```bash
npx vercel
```

## Customize

All content is in `lib/data.ts` — update your GitHub/LinkedIn URLs, projects, and bio there.
